Everything the app does, from a script or an agent

Every screen is also a CLI command that answers in JSON on stdout, with exit codes that say what went wrong. althistory mcp gives Claude, Cursor or any MCP client the same tools.

Install it

You need Node 20 or later. npm link puts althistory on your PATH, which the MCP configs below assume; without it, use the full path to bin/althistory in the repository.

Local mode keeps every graph in JSON files, so there is no database to set up. althistory status reports the mode it is running in.

Use the CLI

Every command prints JSON on stdout and its progress on stderr, so its output can go straight into a script or an agent. althistory schema prints the JSON Schema of every command, with the required options marked, so an agent can learn the tool by reading it.

Generating a history from a premise uses a model when ANTHROPIC_API_KEY or OPENAI_API_KEY is set; without one you get a template to fill in. Ingestion reads text with patterns offline and adds a model when it has a key.

Exit codes
0Success
1General error
2Validation failed
3Authentication failed
4Not found
5Connection failed

Connect an agent over MCP

althistory mcp is a stdio MCP server with the same tools as the CLI. Add it to Claude Desktop, Cursor or Claude Code, and the agent can build, branch and query histories for you.

althistory schema --mcp prints the tool dictionary the server offers.

You never start althistory mcp yourself: your client runs it when it needs the tools, and talks to it over stdin and stdout.

What an agent sees

A request, the tool call the agent makes, and what comes back. Every tool answers in JSON, so the agent can read the result and decide what to do next.
