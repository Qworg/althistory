Build histories with an agent, real or invented

Every screen of the app is also a CLI command that answers in JSON, and althistory mcp gives Claude, Cursor or any MCP client the same tools. Bring a premise from real history, or a world nobody has written yet. The agent does the writing, and althistory checks that the dates and causes hold together.

Install it

You need Node 20 or later. npm link puts althistory on your PATH, which the MCP configs below assume; without it, use the full path to bin/althistory in the repository.

Local mode keeps every graph in JSON files, so there is no database to set up. althistory status reports the mode it is running in.

Connect an agent over MCP

althistory mcp is a stdio MCP server. Add it to Claude Desktop, Cursor or Claude Code, and the agent can create graphs, write events, ages and causal links, check them, and branch them for you.

The server also offers three prompts, one for each way of working described below. Claude Code lists them as slash commands, such as /mcp__althistory__worldbuild.

You never start althistory mcp yourself: your client runs it when it needs the tools, and talks to it over stdin and stdout. althistory schema --mcp prints the tools it offers.

Three ways to work

Each is a prompt the server offers. Pick it in your client, or just ask in your own words.

Bend real history

Start from a premise and the moment real history turns. The agent drafts what follows, checks the years before the turn against what really happened, and makes each consequence show its causes.

“Draft a history where Byzantium wins at Manzikert, then show me where it’s weakest.”

Prompt
alternate_history
Tools
generate_timeline, ingest_text, link_events, branch_timeline

Invent a world

No real history underneath: the agent writes the world’s ages, events and causes, and althistory keeps them consistent. The graph has the world’s own calendar, so the app and the exports show “312 AR”, not 1311.

“Help me build the history of Vael, a drowned archipelago where salt is money.”

Prompt
worldbuild
Tools
create_graph, create_arc, create_event, link_events, validate_graph

Grow what you have

Hand the agent a graph you already have. It reads the whole history, follows one open thread forward, either writing it or simulating it with a preview first, and branches wherever you can’t choose.

“Read my Vael graph and carry the Glass Republic forward fifty years.”

Prompt
grow_history
Tools
export_context, simulate_timeline, validate_graph, branch_timeline

The tool names drop their althistory_ prefix here. Without MCP, althistory prompt worldbuild world="…" --plain prints the same brief for any agent that can run a command.

Inventing a world, start to finish

An abridged session with the worldbuild prompt. The agent sets up the calendar first, lays out three ages, writes the events and links their causes.

Then one link is refused: the agent claimed the glassmakers started the Tide War, but they only joined it eleven years in. Instead of forcing the link, the agent writes the grievance that actually turned them.

Dates stay ISO 8601 underneath. The calendar names the stored year that is the world’s year 1. With an epoch of 1000, 141 AR is stored as 1140, and the tools’ Markdown shows both.

Use the CLI

Every command prints JSON on stdout and its progress on stderr, so its output can go straight into a script or an agent. althistory schema prints the JSON Schema of every command, with the required options marked, so an agent can learn the tool by reading it.

Generating a history from a premise, or a world from a description, uses a model when ANTHROPIC_API_KEY or OPENAI_API_KEY is set; without one you get a template to fill in. Ingestion reads text with patterns offline and adds a model when it has a key.
