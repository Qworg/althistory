See it in time

Events sit inside arcs: the periods that contain them, nested as deep as the history needs. Select an event to trace what it caused; its effects stay lit while the rest fades back.

Or follow one actor through it all, and see the economic, social and political pressures read from clusters of events.

In the demo: open the timeline

Follow the causes

Every link between two events is direct, indirect or contributory, with a weight, a confidence and the evidence for it. Lay the graph out the way that reads best, and find every path from one event to another.

In the demo: open the causal graph, and select an event to find every path from it.

Change one thing

Branch a history at any moment and write what happens instead, with the original drawn faintly beneath. Compare branches side by side, then merge one back through a conflict resolver that flags what doesn't fit.

In the demo: branching and comparing. Merging needs your own install.

Bring in history

Paste text, or give it a Wikipedia article or a Wikidata ID. What it finds comes back in a review table where you edit, drop or keep each event. Nothing is written until you approve.

Patterns read the text offline; an Anthropic or OpenAI key adds a model.

Needs your own install: the demo can't fetch pages. Run it locally

Run it on your machine

You need Node 20 or later, and nothing else: local mode keeps every graph in JSON files, so there's no database to set up. Your own install adds what the demo can't: bringing in history, exporting, merging and simulating.

The app

Clone it, install, and start it. Then open localhost:5173.

For a shared server with Neo4j and Redis, see production deployment.

From a script or an agent

Every screen is also a CLI command that answers in JSON. Link it once, then hand it to your MCP client: the client starts althistory mcp itself, so you never run it in a terminal.
